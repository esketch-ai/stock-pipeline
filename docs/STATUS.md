- 관리자 API 읽기, 오디오/비디오 HTTP Range 응답, 썸네일, 일부 화면 캡처 확인.
- 씬/마무리 정지 프레임 렌더, TypeScript 컴파일 확인. CTA 예시 프레임은 테스트 URL을 사용했습니다.
- Pages 공개 배포 및 실제 화면 확인. 제작 기준가와 10월 12일 종가 비교 데이터 확인.
- 자동 테스트: `test_campaign.py`(3개), `test_pages_export.py`(4개). 설정·추적 계산·동일일 분리·실패 시 보존·스냅샷 불변 검증.
- 과거 `_verify_*.py` 등은 현장 점검용이며 일부는 네트워크 호출·약한 assertion·출력 필터가 있습니다. 정식 전체 회귀 통과로 간주하지 않습니다.

## 알려진 제약 / 후속 작업

1. **장면과 대본 정렬**: 기존 섹션 ID에 고정 씬을 배정합니다. setup 대본이 실제 수급을 설명하지 않을 수 있습니다. 최종 다듬기로 본문이 바뀌어도 원래 sections가 남아 문자 기반 시간 매핑이 어긋날 수 있습니다. 실발화 경계 정렬과 섹션별 근거 연결이 필요합니다.
2. **렌더 시 시장 데이터**: stage4가 수급을 다시 조회하므로 과거 팩트와 날짜가 섞일 수 있습니다. 생성 시점 수급 스냅샷 저장으로 보완해야 합니다.
3. **SVG 정확도**: 캔들 몸통 위치, 포인터와 차트 도메인 일치, 180봉과 52주 표기의 구분 등 추가 검토가 필요합니다. 스윙 가격은 지지·저항 확정값이 아닌 후보입니다. levels 씬의 전용 가격선 표시는 미완성입니다.
4. **신규 영상 검증**: 개선 시나리오·CTA·선택한 저음 음성을 결합한 전체 영상 재생성·청취 검증은 미완료입니다. Reference 영상 분석도 자막 중심이며 실제 장면·오디오 전수 분석이 아닙니다.
5. **음성 메타데이터**: 로컬 음성명 설명의 성별 정보와 과거 피치 측정은 신뢰할 수 없습니다. 계정별 API 지원과 짧은 샘플로 결정해야 합니다.
6. **관리 화면**: header 대화상자 dispatch, quiet refresh의 `refreshItems`, 텍스트 로그 JSON 파싱, job hidden 스타일, 실패한 subprocess 작업 표시 등 실제 클릭 회귀가 필요합니다. 재생성 경로의 gate/QC 저장·게시 키 일관성도 확인 대상입니다.
7. **버전 이력**: 날짜+종목 아카이브와 ticker별 미디어 파일 때문에 동일일 재제작과 옛 영상 재생을 완전히 분리하지 못합니다. 고유 video/run ID와 독립 미디어 경로가 후속 과제입니다.
8. **DB 전환**: 랜딩페이지·개인정보 수집·CRM·이벤트 수집·계약 매출 귀속은 아직 미구현입니다. CTA와 UTM 생성까지 구현됐으며 설명란 링크 자동 삽입도 미연결입니다.
9. **가격 비교**: 단순 명목 가격 증감률입니다. 과거 조정가격 팩트와 미조정 종가 비교는 권리변동 시 오해를 줄 수 있습니다. 거래정지/누락 시 D+N은 관측일 기준입니다.
10. **배포 가용성**: 가격 갱신은 현재 Mac에 의존합니다. GitHub Actions나 상시 서버에서 독립 갱신하는 구조는 아닙니다. Linux/다른 Mac의 새 계정으로 전체 E2E는 재검증이 필요합니다.

## 우선순위

1. 새 환경에서 게시 없는 단일 영상 완주 및 폰트/자막/음성 검수.
2. 제작 시점 데이터 스냅샷과 대본-씬 경계 정합성 확보.
3. 관리자 클릭·실패 처리 회귀.
4. 영상 ID별 버전 저장 및 가격 추적 기준 정교화.
5. 실제 자료·신청 페이지 연결과 전환 측정.
