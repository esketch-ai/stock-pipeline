# 종목별 대본 편집 기준

참고 자료: [세계적으로 유명한 투자자들의 비법과 노하우](https://wikidocs.net/212441), 2026-10-13 열람.
모델 가중치를 재학습한 것이 아니라 아래 내용을 생성 파이프라인의 편집 계획에 반영했다.

## 자료에서 가져온 분석 관점

- 워렌 버핏: 기업 가치와 시장 가격을 구분하는 질문.
- 조지 소로스: 시장 움직임에 대한 가설과 반대 증거의 비교.
- 피터 린치: 관찰을 기업 조사로 연결하는 질문.
- 레이 달리오: 원칙에 따른 위험 구분과 판단 과정.
- 칼 아이칸: 기업 변화의 주주 영향.

위 항목은 편집용 요약이며 직접 인용문이 아니다. 원문의 불명확한 인물 소개(마크 젠센, 메리 디스터, 존 보그린), 인덱스 펀드 창시자 관련 서술 등은 검증 없이 카탈로그에 추가하지 않았다. 원문은 종목별 사실의 근거로 사용하지 않는다.

## 생성 순서

1. 실제 팩트에 적용 가능한 관점을 고른다. 사업 자료가 없으면 린치 관점, 검증된 기업 공시가 없으면 아이칸 관점을 배정하지 않는다.
2. 배치에서 이미 배정된 관점과 전개를 집계해 분산한다. 균형 배정만으로 독창성이 보장되지는 않는다.
3. 전체 대본 전에 핵심 질문, 실제 근거 2개, 반증, 결론, 7개 구간 내용을 작성한다.
4. 각 구간은 이 편집 계획을 따른다. 전체 투자자 목록과 고정 리스크 세 시나리오를 다시 주입하지 않는다.
5. 최종 원문을 비교한다. 문구 중복률은 보조 지표이며 동일 결론·같은 인용·같은 논리 전개를 직접 확인한다.

관점은 종목의 실제 사업과 자료를 대신할 수 없다. 데이터가 시세에 국한된 경우, 15편 모두 기업 고유 분석으로 차별화됐다고 주장하지 않는다.

검토 실행: `venv/bin/python tools/verify_editorial.py`
검토 결과는 `data/editorial_review/<생성시각>/`에 원문, 팩트, 편집 계획과 함께 저장한다.

## 인물 캐릭터와 투자 기법

추가 참고: https://brunch.co.kr/@kimwoss/84 (2026-10-13 열람).
글의 10인 구성에서 해설용 프로필을 만들었다. 인물의 최신 재산·수익률·생존 여부·이사회 경력 및 따옴표 발언은 이 글만으로 대본에 옮기지 않는다.

`remotion/src/components/InvestorCharacter.tsx`는 직접 작성한 로컬 SVG 캐릭터 초안이다.
원문 사진의 자동 변환 결과나 정밀 초상화가 아니다. 안경·머리·수염·의상색을 구분한 편집용 일러스트다.
`investorProfiles.ts`에는 10인의 이름과 직접 인용이 아닌 투자 원칙 요약이 있다.

렌더 흐름은 `editorial_plan` → `character_insight()` → `investorInsight` → `wisdom` 장면이다.
실제로 배정된 투자 관점의 인물만 표시한다. 신규 장편 생성과 아카이브를 통한 재빌드에 연결되어 있으며, 이전 영상은 자동 변경되지 않는다.
캐릭터는 입장 모션과 함께 해당 원칙 및 종목 고유 질문을 표시한다.

시세만으로 사용 가능한 관점 5개와 전개 방식 3개를 조합하여 15편의 계획을 분산한다.
사업·재무·공시 기반 관점은 필요한 입력이 있는 경우에만 사용한다.

미리보기:
```bash
cd remotion
npx remotion still src/index.ts InvestorGallery ../output/investor_characters_preview.png --frame=90
npx remotion render src/index.ts InvestorGallery ../output/investor_characters_preview.mp4
```
