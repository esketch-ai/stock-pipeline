## 계산 기준

`(후속 거래일 종가 / 영상 제작 팩트 기준가격 - 1) × 100`

제작 당시 팩트 가격은 최초 등록 후 변경하지 않습니다. 과거 영상의 제작 시각은 아카이브 저장 시각으로 표시하며 새 아카이브에는 영상 파일 수정 시각을 기록합니다. 동일 날짜·종목의 아카이브는 현재 1건만 존재하므로 별도 재제작 버전은 추적되지 않습니다.

최신 종가는 기준일도 조회하여 별도의 `latestQuote`에 보관합니다. 같은 날 영상 기준가격과 종가가 달라도 제작 기준가는 변경하지 않습니다. D+1/5/20은 기준일 이후·제작 이후의 후속 시세 관측일 순서이며 기준일·휴장·거래정지일은 추가하지 않습니다. 장중 당일 가격은 기록하지 않고 18시 이후 조회합니다. 배당/수수료 및 분할/병합은 보정하지 않는 단순 가격 비교입니다. 기준가의 역사적 조정 여부는 기존 팩트 수집 기준을 따릅니다.

기준가격 미확인, 후속 시세 대기, 시세 조회 실패를 구분합니다. 실패하면 기존 시세를 유지하며 0%로 바꾸지 않습니다. 시세 공급자의 후속 일별 가격 정정은 반영하지만 제작 기준가는 불변입니다.

## 공개 범위

내보내는 데이터는 종목명/코드, 제작·기준 날짜, 기준가, 일별 종가 및 증감률입니다. 관리자 서버 기능(실행·편집·삭제·게시)은 로컬 대시보드에서 사용합니다. 원본 아카이브, 대본, 연락처 DB, 인증정보, 로컬 파일 경로와 대용량 영상은 배포 저장소에 포함하지 않습니다.
