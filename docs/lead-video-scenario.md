# 종목 분석 → 자료 신청 시나리오

## 장면 설계

| 구간 | 시청자가 얻는 답 | 화면 | 전환 역할 |
|---|---|---|---|
| 오프닝 | 왜 지금 봐야 하나? | 종목명 + 확인된 변화 하나 | 질문으로 관심 유도 |
| 상황 | 무엇이 달라졌나? | 수급 또는 가격·거래량 근거 | 관심을 근거로 연결 |
| 핵심 수치 | 이 변화의 의미는? | 숫자 하나씩 설명 | 첫 질문에 답 제공 |
| 심층 해석 | 무엇을 더 확인해야 하나? | 추세와 확인 조건 | 근거 설명 후 자료 안내 한 문장 |
| 리스크 | 반대 상황에서는? | 유지·횡보·이탈 조건 | 분석의 한계까지 설명 |
| 체크리스트 | 내가 다시 볼 것은? | 확인 항목 세 가지 | 자료의 활용 이유 형성 |
| 정리 | 결론과 다음 행동은? | 요약 + 자료명 + 신청 경로 | 설명란 링크로 단일 CTA |

예시 오프닝: “가격은 올랐는데 거래량도 같은 방향일까요? 오늘은 이 움직임이 이어지려면 무엇이 확인돼야 하는지 살펴보겠습니다.” 실제 데이터와 방향이 맞을 때만 사용합니다.

제안 자료 예시: **종목별 가격·거래량 확인 체크리스트**. 실제 제공 자료를 준비한 뒤 설정합니다. 영상 안에서 분석의 답을 제공하고, 자료는 다시 확인하기 편한 형태로 제안합니다.

## 설정

`contact.txt` 에 실제 제공 내용과 운영 중인 주소를 입력합니다. 텍스트 파일이며 `.gitignore` 대상이고 소스 번들에도 포함되지 않습니다. 배포용 예시는 `contact.example.txt` 입니다.

```text
name: OO 종목분석
email: help@example.com
phone: 02-1234-5678
channel: 설명란 자료 신청 링크
url: https://운영중인도메인/신청
offer: 종목별 가격·거래량 확인 체크리스트
note: 자료 구성과 수령 방법은 신청 페이지에서 확인하세요
business: 대표자 홍길동
```

`contact.txt` 를 쓰지 않고 환경변수로만 채우려면 `.env` 에 `CONTACT_PROVIDER`, `CONTACT_EMAIL`, `CONTACT_PHONE`, `CONTACT_BUSINESS` 를 추가합니다. 환경변수가 `contact.txt` 를 덮어씁니다.

```dotenv
LEAD_OFFER=종목별 가격·거래량 확인 체크리스트
LEAD_CAMPAIGN=stock-analysis
CONTACT_CHANNEL=설명란 자료 신청 링크
CONTACT_URL=https://운영중인도메인/신청
CONTACT_NOTE=자료 구성과 수령 방법은 신청 페이지에서 확인하세요
```

`offer` 또는 유효한 HTTP(S) 주소가 없으면 대본의 자료 신청 유도와 마지막 신청 영역은 비활성화됩니다. 이메일·전화만 있어도 QR 이나 신청 안내는 생성되지 않습니다. 이메일·전화 형식이 맞지 않으면 해당 항목을 화면에서 제외합니다. 변경 후 대본·음성을 다시 생성해야 내레이션에도 반영됩니다.

QR 은 `cache/contact/qr.png` 에 로컬 생성됩니다(`segno`, 외부 API 호출 없음). 주소가 바뀌면 자동으로 다시 만듭니다. 영상이 끝나기 전에도 상단에 계속 노출하려면 `CONTACT_QR_PERSISTENT=1` 을 설정합니다(기본은 마무리 카드에만 표시).

렌더 props의 `contact.url`에는 `utm_source=youtube`, `utm_medium=video`, 캠페인명, 종목 코드가 포함됩니다. 이 주소를 설명란에 사용합니다. 화면에는 추적 매개변수 없는 주소를 표시합니다. 설명란 자동 반영과 랜딩페이지는 아직 연결되지 않았습니다.

제공자 정보를 영상에 남기면 되돌릴 수 없으므로, 공개할 항목만 채웁니다. 실제 판매·유료 자료 제공을 시작하면 통신판매법상 사업자 표시가 필요하므로 `business` 를 채웁니다. 제휴나 비용 지급이 있으면 YouTube 설명란의 유료 프로모션 표시도 확인해야 합니다.

## 랜딩페이지 연결 설계

자료 내용·예시 → 수령 방법 → 이름/연락처와 선택형 관심 종목 → 수집 목적·보유기간 안내 및 동의 → 신청 완료 순서로 구성합니다. 상담을 제공한다면 상담 희망 여부를 별도로 받습니다. 실제 제공하지 않는 무료 상담·마감·한정 혜택은 넣지 않습니다.

## 성과 측정

- 시청 유지: 첫 30초 유지율, 평균 시청 시간, CTA 구간 도달률
- 유입: 영상/종목별 링크 클릭 → 랜딩 방문 → 신청 완료
- 유효 DB: 중복·잘못된 연락처를 제외한 신청, 연락 성공, 상담 희망
- CPL: 집행비 ÷ 유효 DB 수
- 계약 전환율: 계약 수 ÷ 유효 DB 수
- ROAS: 귀속 매출 ÷ 광고비 / ROI: 귀속 이익 ÷ 총투입비

처음에는 오프닝 두 버전과 자료 제안 두 버전을 따로 비교합니다. DB 수뿐 아니라 연락 성공률과 계약 전환율도 함께 봅니다. 이벤트 수집·CRM·매출 귀속은 별도 연결이 필요합니다.
